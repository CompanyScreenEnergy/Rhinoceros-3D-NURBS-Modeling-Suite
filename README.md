## Features

- Ready-to-use modeling templates for product, furniture and architectural design
- Grasshopper definition examples for parametric and generative workflows
- NURBS surface and solid modeling guides for clean geometry
- Rendering and visualization presets for V-Ray, Enscape and Rhino Render
- Layer, block and material organization documentation
- Python and RhinoScript examples for workflow automation
- Step-by-step tutorials covering curves, surfaces and solid operations
- Real-world examples demonstrating efficient NURBS modeling workflows

## Requirements

- Windows 10/11
- Installed Rhinoceros 3D

## Usage

Open the extracted folder and explore the template and definition directories. Import the included `.3dm` templates and Grasshopper definitions directly into Rhinoceros 3D, or follow the documentation to configure layers, materials, rendering and scripts. The guides provide practical instructions for each resource.

## About

This repository contains a comprehensive set of tools, templates and educational materials designed to improve NURBS modeling, parametric design and visualization workflows in Rhinoceros 3D.
